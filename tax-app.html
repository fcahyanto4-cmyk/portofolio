Sistem Analisis Kepatuhan Pajak
Sistem ini digunakan untuk membantu menganalisis pola pembayaran pajak perusahaan mulai dari pengolahan data, pemeriksaan kewajiban pajak, hingga pengelompokan wajib pajak berdasarkan tingkat kepatuhan pembayaran.
Masukkan Data

Masukkan data pembayaran pajak melalui file Excel atau input manual dengan mudah.

Pembersihan Data

Membersihkan data ganda dan memastikan data siap digunakan untuk proses analisis.

Pemeriksaan Kepatuhan

Menentukan status pembayaran pajak seperti tepat waktu, terlambat, atau belum bayar.

Ringkasan Data

Menyusun data menjadi informasi yang lebih sederhana dan mudah dianalisis.

Pengelompokan Wajib Pajak

Mengelompokkan wajib pajak berdasarkan pola kepatuhan pembayaran menggunakan metode K-Means.
